# TechNova Solutions

TechNova Solutions is a modern and responsive business website created as a web development project.

## Features

- Responsive business website
- Hero section with project inquiry form
- Services section
- Why Choose Us section
- Technologies section with Bootstrap tabs
- FAQ accordion
- Client reviews
- Contact/CTA sections
- Responsive design for mobile devices
- Bootstrap modals and tooltips
- Font Awesome icons

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- Google Fonts

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
